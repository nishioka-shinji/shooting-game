# shooting-game

ブラウザで遊べる縦型のボス戦シューティングゲームです。HTML ファイル 1 つで動き、ビルドや外部ライブラリは不要です。

## 遊び方

`shooting.html` をブラウザで開くだけで始まります。

```sh
open shooting.html
```

### 操作

| キー | 動作 |
|---|---|
| ← / → | 左右に移動 |
| Space | 通常弾を発射。押し続けて 1 秒後に離すとチャージショット |
| ↓ | 押している間バリアを張る（攻撃不可） |
| ↑ | 必殺ビーム（条件を満たしたときに 1 回だけ） |
| R | ゲーム終了後にリスタート |

## ルール

敵は体力が 0 になると次の形態に変わり、第三形態まで戦います。敵の第三形態を倒せば勝利、プレイヤーの体力が 0 になると負けです。

### プレイヤー

- 青い戦闘機。体力は 5

| 攻撃 | ダメージ | 説明 |
|---|---|---|
| 通常弾 | 1 | Space を押すたびに 1 発 |
| チャージショット | 5 | Space を 1 秒押し続けてから離す |
| 跳ね返した弾 | 1 | バリアで敵の弾を跳ね返す |
| 必殺ビーム | 10 | 体力 3 以下のとき ↑ で発射。ゲーム全体で 1 回だけ。敵のバリアを貫通 |

### 敵

左右にランダムに動き、ランダムなタイミングで弾を撃ってきます。弾は 1 発 1 ダメージです。

| 形態 | 姿 | 最大体力 |
|---|---|---|
| 第一形態 | ゴーレム | 20 |
| 第二形態 | ケンタウロス | 25 |
| 第三形態 | ドラゴン | 30 |

第三形態のドラゴンはランダムにバリアを張ります（3 秒持続）。バリア中も攻撃してきます。バリアに当たったプレイヤーの弾は跳ね返され、プレイヤーに当たると 3 ダメージです。跳ね返された弾は自分のバリアでさらに跳ね返せます。
